# Code of conduct

## Our commitment

Gitrune contributors and maintainers commit to providing a welcoming, safe, and harassment-free environment regardless of experience, identity, background, disability, appearance, nationality, religion, or personal characteristics.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and code rather than people.
- Accept constructive feedback and acknowledge mistakes.
- Respect privacy and avoid publishing another person's personal information.
- Prioritize project safety and users' repository data over winning an argument.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, sustained disruption, doxxing, or retaliation are not tolerated in project spaces.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently restrict participation when behavior violates this policy. Enforcement decisions should be proportionate, private where possible, and documented for maintainers.

Report conduct concerns privately to the repository owner using the contact method published on their GitHub profile. If no private contact method is available, open an issue containing no sensitive details and ask for a private reporting channel. Do not publish personal information in an issue.

This policy applies in the repository, issue tracker, pull requests, project discussions, and public spaces where someone represents Gitrune.
