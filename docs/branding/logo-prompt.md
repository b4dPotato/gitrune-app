# Gitrune logo

The naming in this design brief was updated to Gitrune after the original concept was approved. The approved symbol is unchanged.

Created with the built-in image generation tool. The G-shaped commit graph reflects the app's repository history, branching, and merging workflows. Teal and charcoal come from the existing application theme.

Asset: `gitrune-logo.png`. This is the preserved approved concept. The production brand kit derives its geometry from this artwork and supplies the application's new platform icons separately.

## Generation prompt

Use case: logo-brand
Asset type: final standalone logo symbol for Gitrune, a Windows desktop Git client.
Primary request: Create a polished, distinctive, minimal logo that combines a capital G with a branching Git commit graph. This local-first app visually manages repositories, commits, branches, merges, and worktrees. Convey clarity, control, and connected history.
Design: a single bold geometric G-shaped route with an integrated secondary branch and three carefully placed circular commit nodes. The graph and letter must read as one cohesive symbol, not a letter with a separate icon beside it. Simple intentional negative space, consistent thick strokes, gently rounded corners, excellent legibility at small app-icon sizes. Balanced optically centered silhouette.
Color palette: use the project's mint teal #34c0a2 for the mark and deep charcoal #0e1216 for a rounded-square app-icon tile. A restrained lighter mint node accent is acceptable.
Composition: one large centered rounded-square icon, front-facing, with generous internal breathing room. Transparent canvas outside the rounded square. Square image, high resolution.
Style: flat vector-like precision, crisp clean solid shapes, premium understated developer tool identity.
Text: no wordmark, no extra text.
Avoid: orange Git diamond, existing brand logos, generic circuit-board complexity, more than three commit nodes, thin fragile lines, gradients, glow, 3D, shadows, texture, mockups, presentation boards, multiple variants, watermarks.
